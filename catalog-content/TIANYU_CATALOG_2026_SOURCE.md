# Tianyu 2026 Transformer Catalog Integration Source

This file records the source boundary for the V3 website/catalog update.

## Source material

The V3 supplement is based on user-provided photographs of the official Tianyu transformer catalog, including company overview pages, product overview / contents pages, and numbered pages P01-P29. The uploaded set covers:

- Large-sized oil-immersed transformers: P01-P07
- Small and medium-sized oil-immersed transformers: P08-P13
- Dry-type transformers: P14-P17
- Prefabricated substations and PV/BESS integrated equipment: P18-P23
- Production line, equipment manufacturing and test capability: P24-P29

The contents list also references P30-P32 certificates, but those pages were not part of the supplied photo set, so V3 does not invent or add their certificate details.

## Evidence policy

The new catalog provides **series capability**: standard voltage/capacity ranges, published loss/impedance tables, manufacturing capability, product application descriptions and catalog GA drawings.

The existing website already contains **model-specific evidence**: third-party test reports, TÜV / CE / efficiency evidence and exact tested reference models.

V3 keeps these layers separate:

1. Series capability from the official Tianyu catalog.
2. Tested references from named reports and exact models.
3. Third-party conformity evidence tied to the exact tested configuration.
4. Project reference records from the existing website database.

A catalog series claim is not automatically rewritten as blanket third-party certification.

## Known source conflict retained for reconciliation

The existing website data says the company was established in **1996**. The newly supplied official catalog says **1995** and states that predecessor history can be traced to 1920. V3 intentionally does not overwrite the website establishment year until the company confirms how the two dates should be reconciled (registration / reorganization / establishment definition).

## EU Tier 2 note

Several Tianyu catalog parameter tables state that PEI complies with EU Tier 2 requirements under (EU) 2019/1783 and (EU) No 548/2014. V3 may present this as published catalog series data, but the website's existing model-specific TÜV / CE / Ecodesign evidence remains the basis for exact verified configurations.
